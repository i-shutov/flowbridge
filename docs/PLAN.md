## Результаты по версиям

| Версия | Результат |
| --- | --- |
| 0.3.0 | GUI/CLI, профили, управляемый SSH/SOCKS5, watchdog, пул с проверкой 512 совокупных потоков, installer и Win11 приёмка |
| 0.4.0 | Прозрачное перенаправление Windows-приложений через WFP/ALE с нативной проверкой и подписанным драйвером |
| 0.5.0 | Расширенная устойчивость и подтверждённый сетевой охват |
| 1.0.0 | Полная приёмка заявленной функциональности и платформ, подписанная поставка |

Общее ядро остаётся на Rust, Windows GUI — native Win32/C++, macOS — SwiftUI
поверх C ABI. macOS имеет отдельный путь приёмки и не задерживает первый
Windows выпуск. Даты назначаются после проверки реального кандидата.

## Активный блок

1. Следующий private candidate с исправлениями metadata/notices из PR #94.
2. Нагрузка **512 соединений через настоящий пул FlowBridge**. Raw512 одного
   OpenSSH сохраняется как самостоятельная диагностика зависимости.
3. Функциональная и визуальная приёмка нового кандидата на предоставленной Win11.
4. Параллельная реализация владения и завершения WSK для будущего WFP-режима.

Задачи распределяются четырём субагентам GPT-6.2 Sol / high. Основной агент
публикует план до начала этих задач, интегрирует и проверяет их результаты.

**Win10 не трогать.** Frozen beta.3 сохраняется. Win11 приёмка теперь входит
в текущую работу, но ещё не выполнена. Поставка внутренняя; публичные бинарники,
Release/tag и ослабление защиты не входят в поручение.
Прежние результаты и планы доступны в Git history и датированных evidence.
