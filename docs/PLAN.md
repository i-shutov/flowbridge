## Результаты по версиям

| Версия | Результат |
| --- | --- |
| 0.3.0 | GUI/CLI, профили, управляемый SSH/SOCKS5, watchdog, пул с проверкой 512 совокупных потоков, installer и Win11 приёмка |
| 0.4.0 | Прозрачное перенаправление Windows-приложений через WFP/ALE с нативной проверкой и подписанным драйвером |
| 0.5.0 | Расширенная устойчивость и подтверждённый сетевой охват |
| 1.0.0 | Полная приёмка заявленной функциональности и платформ, подписанная поставка |

Общее ядро остаётся на Rust, Windows GUI — native Win32/C++, macOS — SwiftUI
поверх C ABI. macOS имеет отдельный путь приёмки и не задерживает первый
Windows выпуск. Даты назначаются после проверки реального кандидата.
