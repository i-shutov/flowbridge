# FlowBridge — маршрут к Windows 1.0

**Действующий план с 27 ноября 2026:** [RELEASE_1_0_PLAN.md](../../RELEASE_1_0_PLAN.md).
**Выполнение:** [RELEASE_EXECUTION_20261127.json](RELEASE_EXECUTION_20261127.json).

Новый Win11 runner используется для сборки и инженерной QA. Продуктовая Win10
приёмка остаётся отдельной. Ближайшая поставка — внутренний explicit-SOCKS
кандидат beta.3 с исправлениями SSH; его нельзя переименовывать в защищённый 1.0.

Сначала выполнить R0–R9 нового плана. Затем закрыть signed WFP/ALE kernel authority,
реальный TCP путь, no-DIRECT, DNS/UDP/IPv6, длительную SSH QA, интерфейс и установщик,
замороженный RC и независимое GO. [WIN-00…09](WINDOWS_FIRST_GATES_20261115.json)
сохраняется как контракт требований.

Прежний roadmap полностью сохранён в
[историческом снимке](WINDOWS_FIRST_1_0_ROADMAP_HISTORY_20261117.md).
Его старые платформенные формулировки не заменяют действующий план и не дают
приёмку новому кандидату.
