`5778a734242f10bd0671043e3818b2bcd1b29c9d6a1a6402d91c8f5e8db9953c`.

Оригинальный setup, программа, служба, драйвер и keygen не запускались. Вложенный keygen не распаковывался. Профилей, конфигурации пользователя или исходников в верхнем архиве нет.

PE/version resources: **Proxifier Standard Edition 4.14 x64**, file version `4.14.0.1`, provider/company `VentoByte SL`. Setup — Inno Setup; наличие certificate table не было принято за проверку подлинности подписи. Список setup содержит варианты компонентов для разных архитектур; извлечённый набор не используется как эталон установленных файлов конкретной ОС.

## Наблюдаемые компоненты

| Компонент | Вывод для собственной реализации |
|---|---|
| `Proxifier.exe` | Нативный desktop UI, профили, правила, просмотр соединений/трафика |
| `ProxyChecker.exe` | Нужна отдельная диагностика доступности upstream; FlowBridge реализует CLI `check` |
| `ServiceManager.exe` | Жизненный цикл системных компонентов должен быть отделён от обычного UI |
| `ProxifierShellExt.dll` | Интеграция оболочки — отдельная возможность; в FlowBridge пока не включена |
| `Driver/ProxifierDrv.inf`, `.sys`, `.cat` | Windows-системный режим использует драйверный путь; обычного локального SOCKS listener недостаточно |

INF объявляет класс `WFPCALLOUTS`, kernel service и зависимость от `BFE`, содержит архитектурные секции x86/amd64/arm64. DriverVer: `08/28/2023,18.49.12.492`. Это подтверждает выбор WFP как платформенного механизма для самостоятельной Windows-реализации; содержимое чужого драйвера не переносилось.

Из version/string/menu ресурсов проверены категории функций: профиль, правила проксификации, цепочки, разрешение имён, журнал и трафик, параметры службы. Ресурсы не копируются в интерфейс FlowBridge. Поведенческая совместимость оригинального приложения не проверялась запуском, поэтому статическая инвентаризация не означает полной совместимости.

## Сопоставление с FlowBridge 0.2

| Возможность | Результат |
|---|---|
| Прокси и цепочки | Реализованы, протоколы покрыты локальными интеграционными тестами |

## Воспроизводимость и происхождение

Для поведения/API использованы первичные документы Microsoft, Apple, RFC и публичное руководство Proxifier; ссылки приведены в ARCHITECTURE и PLATFORMS. Исходники FlowBridge написаны самостоятельно. Референс, extracted payload и ключевые материалы не входят в source ZIP или installer.
