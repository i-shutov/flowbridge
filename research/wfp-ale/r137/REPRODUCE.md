# R137 local reproduction (offline logic only)

From the `r137` directory:

```
python3 r137_oracle.py
node r137_independent.mjs
python3 -m unittest r137_acceptance.py -v
```

`R134_RECEIVED_ACCEPTANCE.json` was generated by parsing the owner's R134 ZIP,
validating all JSON records against the R134 checkpoint validator, and omitting
raw paths/PIDs/FileIDs/AppIds. The original uploaded ZIP stays local.

`FlowBridge-R137-MissingAppId.ps1` is Windows PowerShell 5.1 and intentionally
**not** executed in this Linux runtime. It requires existing Rust x86_64 MSVC.
Only explicit `-RunReadOnlyMissingName` invokes Win32/WFP read-only APIs.
No driver, policy or network experiment is enabled.
